# 数据集说明 — 煤矿钻场工序指示牌（signage）

## 1. 任务定义

煤矿钻场施工过程中，工人需要在不同工序环节（开孔、见煤、验煤、止煤、终孔、验孔、封孔）
举示对应的**工序指示牌**，便于地面管理人员通过监控视频了解井下施工进度。
本数据集用于训练"工序指示牌"检测与牌面文字识别模型，是视频自动剪辑算法的基础。

## 2. 类别定义

| 类别 ID | 名称 | 说明 |
| --- | --- | --- |
| 0 | `signage` | 工序指示牌（含牌面文字） |

牌面文字（七道工序）由 PaddleOCR 在推理阶段识别，不属于检测类别：

```
开孔 → 见煤 → 验煤 → 止煤 → 终孔 → 验孔 → 封孔
```

## 3. 标注规范

- 格式：YOLO（`class cx cy w h`，归一化到 [0,1]）；
- 标注工具：LabelImg / roLabelImg；
- 标注原则：指示牌出现即标注，允许部分遮挡；同一画面多个指示牌分别标注；
- 质检：双人交叉抽检，争议样本由第三人裁定。

## 4. 规模与划分

按 8 : 2 划分为训练集与验证集（**先划分、后增强**，避免同一视频的相邻帧同时
出现在两侧造成数据泄漏）。

| 数据来源 | 训练集 | 验证集 | 合计 |
| --- | --- | --- | --- |
| 矿井 A | 2 344 | 586 | 2 930 |
| 矿井 B | 1 056 | 264 | 1 320 |
| 矿井 C | 954 | 228 | 1 182 |
| 矿井 D | 720 | 180 | 900 |
| **合计** | **5 074** | **1 258** | **6 332** |

> 按合作矿井的授权范围，公开文档中以“矿井 A–D”代称具体矿名，原始名称仅在受限台账中保留。

另保留 `images/test/` 与 `labels/test/` 目录（少量留样，固定不参与训练与调参），
用于最终效果抽查。

图像为监控视频抽帧（1080p/720p 混合），覆盖白天/夜班、低照度、粉尘、水雾、
逆光、雨天等复杂工况，并按施工阶段均匀采样，避免工序分布倾斜。

## 5. 采集与脱敏

- 来源：煤矿钻场现场监控录像（已获使用授权）；
- 采集方式：按时间窗等间隔抽帧 + 关键事件（举牌动作）附近加密抽帧；
- 脱敏处理：
  - 不含可识别个人身份信息（无人员面部特写、无工牌号码）；
  - 涉及敏感地理信息的图像元数据（EXIF）已剔除；
  - **公开样例图**已用黑色遮罩带覆盖画面顶部与底部各 13.5% 区域，
    用于遮挡监控摄像头叠加的 OSD 信息（时间戳、企业 logo、钻场编号与作业地点）；
  - 遮罩带仅覆盖摄像头叠加层，不覆盖画面中央的指示牌目标，因此样例的
    YOLO 标注坐标仍然有效（相对坐标不受等比缩放影响）。

## 6. 获取方式

- 完整数据集（6,332 张增强后图像 + YOLO 标注）因涉合作矿井生产信息，**不入公开
  仓库**；评审期内可通过受限仓库或网盘按需申请访问，链接见作品提交页
  【作品其他材料链接】；
- 本仓库 `samples/` 目录提供 **10 张脱敏样例图**（6 张 train + 4 张 val）供快速
  验证，覆盖"开孔 / 终孔 / 验孔 / 封孔"四类工序与过曝、倾斜、低照度等困难工况；
- 若仅需复现推理效果，可直接使用 `weights/best.pt` + 样例视频，无需下载全量数据集。
