## 二、AGPL-3.0 义务的履行方式

Ultralytics YOLO11n 为 AGPL-3.0。本作品修改了其网络结构与损失函数，属于衍生
作品。团队的处理方式：

1. **同许可发布**：包含 Ultralytics 衍生代码的部分整体以 AGPL-3.0 发布，
   保留原版权与许可声明（见 `LICENSE`）；
2. **标注修改点**：`train/piouv2_patch.md` 逐条列出改动的文件、行号与代码片段，
   并在 `README.md` 中说明修改内容；
3. **网络服务条款**：若以网络服务形式对外提供，将按 AGPL 第 13 条向使用者提供
   对应源代码的获取方式；
4. **现场部署边界**：煤矿现场部署为**内部使用**，不构成对外分发。

## 三、已主动整改的两项许可风险

### 3.1 ffmpy（GPL-3.0）→ subprocess 直调 FFmpeg

- **风险**：开发早期使用 `ffmpy`（GPL-3.0 的 Python 封装）调用 FFmpeg，
  随作品分发会带来 copyleft 传染风险。
- **整改**：已改为以 `subprocess` 子进程方式调用系统中已安装的 FFmpeg 二进制
  （见 `backend/ai_engine.py` 的 `_get_ffmpeg_path()`），**彻底移除 ffmpy 依赖**。
- **现状**：FFmpeg 仅被调用，未修改、未链接、未再分发其源码，仅需保留许可与
  版权声明。合规状态：已核验。

### 3.2 SimHei（专有字体）→ Noto Sans SC 思源黑体（SIL OFL 1.1）

- **风险**：视频叠加文字原使用 SimHei，为专有字体，**不得随作品再分发**。
- **整改**：仓库 `fonts/` 内置 Noto Sans SC 思源黑体（SIL OFL 1.1，允许嵌入与
  再分发），随仓库分发并保留许可声明。
- **现状**：程序按"仓库内置思源黑体 → 系统 SimHei（仅本机回退，不随仓库分发）
  → PIL 默认字体"顺序加载，专有字体文件本身不进入仓库。合规状态：已核验。

## 五、数据与权利边界

- 监控视频由合作矿井提供，已取得用于本作品研发、测试与评审展示的授权；
  原始视频**不出矿、不上传公网**
- 训练数据在标注阶段即完成脱敏：不含人员面部特写、工牌号码与人员身份信息
- 数据集仅开放结构说明与少量脱敏样例，不开放原始视频与完整标注文件
- 作品不采集、不存储任何个人身份信息，不涉及人脸识别，不使用人脸特征进行判断

## 六、AI 输出与内容安全

- 检测与识别均为**确定性推理**，不生成文本或图像，不存在幻觉类风险
- 存在漏检与误识别风险，应对措施：人工补录入口、低置信度日志标记、
  连续多帧一致才触发工序切换
- 模型**仅用于工序判定**，不用于人员行为定性与处罚
- 作品中不含 AI 生成的代码、图片或音视频内容：全部代码由团队编写，全部图像
  来自系统真实运行结果或自建数据集
