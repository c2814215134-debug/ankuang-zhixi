## 二、任务定义与类别

- **任务**：单类别目标检测 —— 定位钻场作业画面中的"工序指示牌"
- **类别数**：`nc: 1`
- **类别名**：`signage`（工序指示牌）
- **标注方式**：水平矩形框（Labelme 标注后转换为 YOLO txt 格式）

```
# YOLO txt 每行格式
<class_id> <x_center> <y_center> <width> <height>     # 全部归一化到 0–1
```

标注规范：

- 框紧贴指示牌四边，不含多余背景
- 牌面被部分遮挡时，按**可见部分**标注
- 严重模糊、无法辨认牌面内容的帧不标注
- 同一帧存在多块指示牌时分别标注

## 三、数据来源与规模

原始数据为**丰阳煤矿**实地录制的打钻监控视频。为提升泛化能力，补充了
**梁北煤矿、鹤煤四矿、鹤煤六矿**的监控录像，以覆盖不同背景环境与目标状态。

| 数据来源 | 训练集 | 验证集 | 合计 |
| --- | --- | --- | --- |
| 丰阳煤矿 | 2 344 | 586 | 2 930 |
| 梁北煤矿 | 1 056 | 264 | 1 320 |
| 鹤煤四矿 | 954 | 228 | 1 182 |
| 鹤煤六矿 | 720 | 180 | 900 |
| **合计** | **5 074** | **1 258** | **6 332** |

划分比例 8 : 2（训练 : 验证），按帧抽取后**先划分再增强**，避免同一视频的
相邻帧同时出现在训练集与验证集造成数据泄漏。

## 四、采集与处理流程

```
煤矿现场监控录像（.mp4/.avi）
   ↓  抽帧
原始图像
   ↓  Labelme 人工标注（矩形框，类别 signage）
XML 标注文件（VOC 格式）
   ↓  dataset/xml2txt.py
YOLO txt 标签
   ↓  dataset/split_data.py
images/{train,val,test} + labels/{train,val,test}
   ↓  Albumentations 增强
最终训练数据 6 332 张
```

相关脚本：`dataset/split_data.py`（划分）、`dataset/xml2txt.py`（VOC→YOLO）、
`dataset/yolo2coco.py`（YOLO→COCO，供其他框架使用）。

## 五、数据增强策略

按井下真实工况设计，每种增强对应一种可观察的现场干扰：

| 增强方法 | 作用 | 模拟的井下工况 |
| --- | --- | --- |
| RandomRain | 添加随机分布雨滴条纹 | 顶板淋水、注水溅起的水滴 |
| RandomSunFlare | 添加随机光晕 | 矿灯强光的视觉过曝 |
| Affine | 旋转、缩放、平移、剪切 | 工人举牌的多种位置形态 |
| ToGray | RGB 转单通道灰度 | 低照度、无彩色的视觉环境 |
| RandomBrightnessContrast | 随机调整亮度对比度 | 不同光照条件下的目标显现变化 |
| Perspective | 四点随机变换矩阵扭曲 | 摄像头视角造成的透视形变 |
| GaussNoise | 叠加高斯噪声 | 低照度下的传感器噪声 |
| RandomShadow | 叠加随机阴影块 | 设备与人员对牌面的部分遮挡 |
| HorizontalFlip | 水平镜像 | 增加位置多样性 |

除上表外，训练中叠加使用了官方默认的 Mosaic（1.0）、MixUp、HSV 色彩扰动
与 Erasing（0.4）等策略。

## 六、脱敏与合规

- 采集已取得合作矿井用于本作品研发、测试与评审展示的授权
- **原始视频不出矿、不上传公网**
- 标注阶段完成脱敏：不含人员面部特写、工牌号码与人员身份信息
- 作品中不采集、不存储任何个人身份信息，**不涉及人脸识别**，不使用人脸特征
  进行任何判断
- 公开发布的版本仅包含结构说明与少量脱敏样例

## 七、目录结构

```
dataset/
├── data.yaml                 # nc=1, names: ['signage']
├── images/{train,val,test}/
├── labels/{train,val,test}/
├── VOCdevkit/                # Labelme 原始 XML 标注备份
├── split_data.py             # 划分脚本
├── xml2txt.py                # VOC → YOLO
└── yolo2coco.py              # YOLO → COCO
```

`data.yaml` 内容：

```yaml
path: ./
train: images/train
val: images/val
test: images/test
nc: 1
names: ['signage']
```

## 八、已知不足与后续计划

- 数据集共 6 332 张，**遮挡与极端逆光样本相对不足**，是极端场景下漏检的主要
  原因（见技术报告第五章表 17）
- 后续计划：扩充遮挡与逆光样本，补充更多矿井与钻场类型
