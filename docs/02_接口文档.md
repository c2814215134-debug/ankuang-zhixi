# 接口文档 · 后端 REST API

后端基于 Flask，默认监听 `http://0.0.0.0:2800`。前端统一在
`frontend/src/api/index.js` 中封装，基址常量 `API_BASE_URL`。

- 请求与响应均为 JSON（`JSON_AS_ASCII = False`，中文原样返回，不做 `\uXXXX` 转义）
- 视频文件接口支持 HTTP Range，可在浏览器中拖动进度条
- 错误统一返回 `{"success": false, "message": "..."}` 与对应 HTTP 状态码

注册校验规则（后端强制）：

- 用户名与密码不能为空
- **用户名必须是字母和数字的组合**
- **密码必须多于 6 位**
- **密码必须是字母和数字的组合**
- 用户名不可重复

## 3. 工序智能分析（核心）

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/analysis/files` | 获取待处理原始视频列表 |
| POST | `/api/analysis/start` | 启动单文件分析任务，请求体 `{filename, frame_skip}` |
| POST | `/api/analysis/upload_and_start` | 上传本地视频、按归档名重命名并自动启动（multipart/form-data） |
| GET | `/api/analysis/status/<task_id>` | 轮询任务状态、AI 判定进度与工序切换记录 |
| POST | `/api/analysis/stop/<task_id>` | 强制终止运行中的任务，保留已完成切片 |
| GET | `/api/analysis/feed/<task_id>` | 任务处理过程的实时画面流（MJPEG，`multipart/x-mixed-replace`） |

**跳帧阈值 `frame_skip`**：取值 1–30，默认 3。表示每 N 帧取 1 帧送入检测。
数值越大处理越快，但可能跨过短暂的工序切换瞬间；数值越小越准，耗时越长。

任务状态流转：`准备中 → AI 处理中 → 已完成 / 已终止`。

## 4. 视频归档库

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/folders` | 归档目录树与各目录视频数量（目录扫描结果缓存 60 秒） |

## 5. 钻孔台账

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/drills` | 钻孔台账列表 |
| POST | `/api/drills` | 新增钻孔记录 |
| PUT | `/api/drills/<id>` | 修改钻孔记录（必填项不可清空） |
| DELETE | `/api/drills/<id>` | 删除钻孔记录 |

新增 / 修改时的 **10 项必填拦截**：

| 字段 | 名称 | 字段 | 名称 |
| --- | --- | --- | --- |
| `hole_number` | 钻孔编号 | `drill_position` | 钻孔位置 |
| `location_id` | 施工地点 | `opening_elevation` | 开孔标高 |
| `team_name` | 施工队伍 | `design_depth` | 设计孔深 |
| `responsible_person` | 责任人 | `actual_depth` | 实际孔深 |
| `dip_angle` | 倾角 | `azimuth` | 方位角 |

任一必填项缺失或为空 → 返回 400 与"保存失败：\[名称\] 是必填项，不能为空！"。
孔深、角度等数值字段若填入非数字 → 返回 400 与格式错误提示。
`video_path` 字段用于把切片与钻孔绑定，实现"一孔一档"的双向跳转。

## 11. 数据表

SQLite（SQLAlchemy ORM），首次启动自动创建。主要表：

| 表 | 说明 |
| --- | --- |
| `user` | 用户账号 |
| `location` | 施工地点 |
| `camera` | 摄像仪（含 RTSP 地址） |
| `drill_records` | 钻孔台账（14 个字段，含 `video_path` 归档关联） |
| `detection_log` | 边缘端上报的识别记录 |
| `system_config` | 系统参数配置 |

## 12. 前端调用示例

```js
import { analysisApi } from '@/api'

// 上传视频并自动开始分析
const fd = new FormData()
fd.append('file', file)
fd.append('archive_name', '戊8-32010-钻孔-001')
fd.append('frame_skip', 3)
await analysisApi.uploadAndStart(fd)

// 轮询进度
const st = await analysisApi.getStatus(taskId)
```
